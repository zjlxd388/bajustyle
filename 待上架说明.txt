BajuStyle 批量上架 — 文件夹规范
================================

把要上架的商品，按下面的结构放进「待上架」文件夹，然后叫我「开始批量上架」即可。
我会本地生成页面 + 自动翻译（若已配 DeepSeek Key），全程不自动部署，确认后再上线。


一、目录结构（照抄即可）
--------------------------------

待上架/
├─ 衣服-短袖\                ← 顶层文件夹 = 分类-子分类（中文，用减号 - 连接）
│  ├─ 纯色短袖T恤\           ← 这个文件夹 = 1 个商品，文件夹名就是商品中文名
│  │  ├─ 正面.jpg            ← 图片，第一张自动当封面，后面是详情图
│  │  ├─ 背面.jpg
│  │  └─ 信息.txt            ← 可选：写价格/描述（不写就用默认值）
│  ├─ 条纹长袖衬衫\          ← 第二个商品
│  │  └─ *.jpg
├─ 衣服-长袖\
│  └─ ...
├─ 鞋子\                     ← 没有子分类时，顶层只写分类名（不要减号）
│  ├─ 小白鞋\
│  │  └─ *.jpg
├─ 包包\
├─ 手表\
├─ 饰品\


二、分类 / 子分类 名字对照（必须照写，否则识别不了）
--------------------------------

分类名（顶层文件夹前半段）：
    衣服 / 鞋子 / 包包 / 手表 / 饰品

子分类名（仅「衣服」需要，顶层文件夹后半段）：
    短袖 / 长袖 / 短裤 / 长裤
    （写其他名字也会自动新建该子分类，比如 衣服-连衣裙）

举例：
    衣服-短袖   → 衣服分类下的「短袖」子分类
    鞋子        → 鞋子分类（无子分类）
    饰品-项链   → 饰品分类下自动新建「项链」子分类


三、每个商品里放什么
--------------------------------

1. 图片：直接把该商品的所有图片丢进商品文件夹。
   - 支持 jpg / png / webp / gif
   - 第一张 = 封面图，其余 = 详情图
   - 图片名随意，脚本会自动重命名为安全文件名

2. 信息.txt（可选，不写也能上架）：

   ⚠️ 商品名「不用」在这里写！文件夹名就是商品名（脚本自动读取）。
      信息.txt 里只写下面两样即可：

   价格=CNY 89.00
   描述=●面料：纯棉
   ●颜色：白/黑/蓝
   ●尺码：S M L XL

   说明：
   - 「名称」不写在信息.txt 里 → 直接用文件夹名当商品名即可（所以不要重复写）
   - 只有当你想要网页显示的名字和文件夹名【不一样】时，才在信息.txt 加一行：
       名称=网页想显示的名字
   - 不写「价格」→ 默认 CNY 0.00（上架后可在管理器改）
   - 不写「描述」→ 留空
   - ⚠️ 描述格式完全自由：上面的「●」只是举例装饰，不是必须的。
     第一行写在「描述=」后面即可；想换行就直接另起一行（不用加任何前缀），
     脚本会自动拼成多行。继续行里不要写「价格=」「名称=」「描述=」这种带等号的行。


四、翻译怎么办
--------------------------------

- 如果你的 config.json 里配了 DeepSeek Key：脚本自动把中文名/描述翻成 英文/马来文/越南文。
- 如果没配：脚本先填中文，并生成「待翻译清单.txt」，由我（助理）帮你翻好再写入。
- 两种方式都会先本地生成，确认后再部署，不会乱上线。


五、怎么触发
--------------------------------

放好文件后，直接对我说：「开始批量上架」。
我跑完会给你一份「批量上架报告」，你核对无误后再说「部署上线」。
