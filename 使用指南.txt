# 🚀 AI模型切换器 - 快速使用指南

## 方法1：直接运行（推荐，无需安装）

### 步骤1：安装依赖（仅一次）

打开命令提示符（CMD），运行：

```bash
pip install requests
```

### 步骤2：运行程序

1. 找到文件：`D:\BajuStyle\运行模型切换器.bat`
2. 双击运行

程序会自动启动！

---

## 方法2：打包成EXE（可选）

### 步骤1：安装PyInstaller

打开命令提示符（CMD），运行：

```bash
pip install pyinstaller
```

### 步骤2：打包成EXE

在 `D:\BajuStyle\` 目录下运行：

```bash
python build_exe.py
```

### 步骤3：找到EXE文件

打包完成后，EXE文件在：
```
D:\BajuStyle\dist\AI Model Switcher.exe
```

---

## 📝 使用说明

### 1. 配置API Key

**智谱AI（BigModel）**
- 访问：https://open.bigmodel.cn/
- 注册并获取API Key
- 在程序左侧输入API Key
- 选择模型（glm-4, glm-4-plus, glm-4-air, glm-4-flash）

**DeepSeek**
- 访问：https://platform.deepseek.com/
- 注册并获取API Key
- 在程序左侧输入API Key
- 选择模型（deepseek-chat, deepseek-reasoner）

### 2. 测试连接

1. 在右侧选择要测试的模型
2. 点击"🚀 测试连接"
3. 查看是否成功

### 3. 发送请求

1. 在输入框输入测试内容
2. 点击"🚀 发送请求"
3. 查看响应结果

### 4. 保存配置

点击"💾 保存配置"按钮
配置会保存到 `config.json` 文件

## 🆘 常见问题

### Q: 双击.bat文件没反应？
A: 确保已安装Python，并且已安装requests库。

### Q: 提示"找不到模块requests"？
A: 运行 `pip install requests`

### Q: 程序无法启动？
A: 检查Python版本是否为3.6+，是否已安装requests。

### Q: 如何卸载？
A: 删除 `model_switcher.py` 和 `config.json` 即可
